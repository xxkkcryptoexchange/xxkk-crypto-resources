## GitHub Pages deployment

1. Create a new GitHub repository named `xxkk-crypto-resources`.
2. Upload the complete project contents to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the GitHub Pages deployment to complete.
7. Your project-site URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/xxkk-crypto-resources/`
8. Replace `YOUR-GITHUB-USERNAME` in:
   - `index.html` canonical and Open Graph URLs
   - `robots.txt`
   - `sitemap.xml`
9. After deployment, submit the final sitemap URL to Google Search Console if appropriate.
